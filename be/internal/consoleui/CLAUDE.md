# consoleui Package

Native Bubble Tea v2 client for server-owned `console_chat` engines. The server catalog drives the resume/new-session picker — resume rows plus brand → model → supported mode (CLI / Direct API) → effort, with Default first and labelled from the model row's `default_effort`; the mode node stamps the engine (`claude`/`codex`/`api`). A running turn renders an animated `working…` spinner at the transcript tail (tick chain starts on every idle→running transition); the main model keeps a bounded, paginated, render-cached transcript and reconciles history, live deltas/thinking, approvals, and turn state on every WebSocket reconnect. Enter submits, `y`/`n` resolves approval (`a` allows the tool for the whole session; the header shows the resulting `always:` list, revocable from the web UI), Ctrl+C interrupts, Ctrl+F searches, Ctrl+G enters viewport/copy mode, Ctrl+D detaches, and Ctrl+X closes.
